# Combinatorics Sketchbook — quick start

1. **Open** `combinatorics-sketchbook.html` in a browser (works offline; progress saves in localStorage).
2. **Check** it any time you edit: `node verify/verify.js`  → must print `ALL CHECKS PASSED`.
3. **Deploy** by replacing the deployed file's contents (live: https://combinatoricssketchbook.vercel.app/). Keep the same URL so J.J.'s saved progress stays.
4. **Read `HANDOFF.md`** before changing anything — §2 (house rules), §7 (gotchas) and §10 (open issues) matter most.
